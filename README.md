# 余烬协议（Ember Protocol）

使用 **Godot 4.x / GDScript** 制作的 2D 俯视角生存肉鸽原型。所有角色、弹幕、场景和特效均由代码绘制，无外部素材或插件依赖。

## 运行

1. 使用 Godot 4.x 打开并导入本目录的 `project.godot`。
2. 等待脚本加载完成后按 **F5** 运行主场景。
3. 点击“开始行动”。

项目默认使用兼容渲染模式，设计分辨率为 1280 × 720。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD / 方向键 |
| 瞄准 | 鼠标 |
| 手动射击 / 临时接管瞄准 | 按住鼠标左键 |
| 冲刺（短暂无敌） | Space |
| 开关自动锁敌 | F |
| 暂停 / 继续 | Esc |
| 选择升级 | 鼠标点击 / 1、2、3 |

## 核心循环

- 击毁敌人，拾取经验晶体并提升同步等级。
- 每次升级从三个随机模块中选择一个，可消耗次数重新校准。
- 敌人会随时间提速增压，并逐步加入高速、坦克和远程单位。
- 生存 3 分钟后监管者入场；击毁 Boss 获胜，生命归零则本局结束。
- 包含 12 类强化、暴击、穿透、多重射击、磁吸拾取、恢复掉落和冲刺冷却构筑。

## 主要文件

- `scenes/main.tscn`：主场景。
- `scripts/main.gd`：游戏状态、波次、射击、升级和界面。
- `scripts/player.gd`：玩家属性、移动和冲刺。
- `scripts/enemy.gd`：普通敌人与 Boss 行为。
- `scripts/projectile.gd`、`pickup.gd`：弹丸与掉落物。
- `scripts/effect.gd`、`damage_number.gd`：战斗反馈。
